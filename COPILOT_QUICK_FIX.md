# GitHub Copilot Quick Fix Reference

## 🚨 Not Getting Suggestions?

### ✅ Quick Checklist (2 minutes)
1. **Check Status Bar**: Look for Copilot icon (bottom-right in VS Code)
2. **Sign In**: `Ctrl+Shift+P` → "GitHub Copilot: Sign In"
3. **Extension**: Install/Update "GitHub Copilot" extension
4. **Restart**: Close and reopen VS Code

### 🔍 Most Common Issues

| Problem | Solution | Time |
|---------|----------|------|
| No suggestions at all | Sign in to GitHub + restart VS Code | 2 min |
| Extension not found | Install "GitHub Copilot" from Extensions | 1 min |
| "Not authenticated" | Command: "GitHub Copilot: Sign In" | 3 min |
| Works in browser, not VS Code | Update VS Code + Copilot extension | 5 min |
| Subscription expired | Check [GitHub Copilot billing](https://github.com/settings/billing) | 1 min |

### ⚡ Test If It's Working
Type this comment in a `.java` file:
```java
// Function to calculate the sum of two numbers
```
You should see a suggestion appear automatically.
